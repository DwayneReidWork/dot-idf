# building
```bash
cmake -B build
cmake --build build
```

# running
```
# start with default port of 5000
./build/network_game

# specify port on startup
./build/network_game <port number>
```

# solutions
- Solutions should be in python and c
- A solution to each level should be encapsulated in its own function
- I recommend using sturcts (c) and classes (python) to maintain game state between levels
